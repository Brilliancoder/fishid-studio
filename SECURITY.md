# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **FishID Studio** (for example in the FastAPI backend, storage adapters, file upload handling, or Docker setup), please **do not open a public GitHub issue**.

Instead, report it privately via [GitHub Security Advisories](https://github.com/viniciusscience/fishid-studio/security/advisories/new) with:

- A clear description of the vulnerability and affected component/file.
- Minimal steps to reproduce.
- Any suggested mitigation if known.

We will acknowledge your report and work on a fix promptly.
